## IME 宿主

`FcitxInputMethodService.createComposeInputView()` 返回 `FrameLayout` 宿主：`InputView` 直接作为子 View，覆盖层 `ComposeView` 压在其上。`themeState`、`recreateNonce`、`stylusUiActive` 由 `syncHostedInputView()` 在组合期同步重建。

不用 `AndroidView` 承载整棵键盘树：互操作会给每帧多测一遍布局。

`input/LifecycleInputMethodService.kt` 负责把 owner 链挂到 IME 的 `decorView`，`ComposeView` 的嵌入依赖它。

## 仍为 View 的组件

这些组件保留 View 实现，改动时按其成因判断能否迁移。

| 组件 | 成因 |
|---|---|
| `input/CandidatesView.kt` | 物理键盘模式的浮动候选，由 `FcitxInputMethodService` 挂载；使用 `PreeditUi`、`PagedCandidatesUi`、`LabeledCandidateItemUi` |
| `input/keyboard/KeyboardTuneOverlay.kt` | custom 调校浮层已迁移为 Compose（`class KeyboardTuneCompose`，由根组合在 `AndroidView(InputView)` 之上渲染），`TuneMetrics` 提升为顶层 |
| `ui/main/settings/theme/KeyboardPreviewUi.kt` | 设置页主题预览，需要实例化 View 键盘 `TextKeyboard` |
| `input/bar/ui/ToolButton.kt` | 多个窗口的 `onCreateBarExtension` 返回 View 按钮 |
| `input/picker/PickerTabsUi.kt`、`PickerPaginationUi.kt` | `PickerWindow` 的 AndroidView island |
| `input/bar/ui/idle/InlineSuggestionsUi.kt` | 系统 API 限制，由 `ComposeKawaiiBarComponent` 的 AndroidView 包装 |
| `input/handwriting/StylusInkView` | 触控笔墨迹需要原生 View 绘制 |
| `input/LifecycleInputMethodService.kt` 之外的主键盘 View 栈 | 上游文件，按 fork 约定保留 |

## 组件边界

- **工具栏与键盘分属两套色源。** 工具栏读 `MiuixTheme.colorScheme`，主键盘键面走 fcitx `Theme` 桥 `keyboard/KeyboardVisuals.kt`。工具栏底部选中项为与键盘底色对比，读原始 `Theme.keyboardColor` 明度，这是有意例外。
- **同框重启不重置面板。** `input/EditorKey.kt` 按 pkg、fieldId、inputType、hintText、imeOptions 判定同框 resync 与换框；同框保留 Picker、剪贴板、展开候选的当前面板。[详见](../约定/README.md)
- **顶部延伸带。** `composeTopView` 在预编辑栏与工具栏之间插入恒高 Box，`InputView.topExtensionPx` 由 `onComputeInsets` 加回 `contentTopInsets`。
