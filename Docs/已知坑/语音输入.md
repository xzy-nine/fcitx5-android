# 语音输入

语音输入的进程边界、打包与平台实现相关的问题与约束。功能与代码归属见 [特性/语音输入.md](../约定/特性/语音输入.md))，第三方插件协议见 [语音插件接入.md](../集成/语音插件接入.md)。

## asr 进程不能碰主进程子系统

内置语音输入的 `:asr` 进程不能碰主进程子系统。

`VoiceAsrService` 跑在 `android:process=":asr"`，该进程只做 dlopen 与读模型文件。`FcitxApplication.onCreate` 里有 `Application.getProcessName().endsWith(":asr")` 的早退守卫，删了它会在 `:asr` 里初始化 `ClipboardManager`（Room）与 `AutoDictSync`（网络同步），出现多进程同开 Room 或凭空后台同步。

同理 `:asr` 没有 `AppPrefs`，所以 AIDL `startAsr` 与 `prepareAsr` 传的是已判定的家族、角色到文件的绝对路径与多语参数（由 app 侧 `VoiceModelStore.resolve()` 解析与判定）。不要改回传 modelDir 后在 `:asr` 里读偏好或让服务自己猜家族，判错会 `_Exit` 杀掉 `:asr`。

## onnxruntime 由 ai.onnxruntime 提供

`libonnxruntime.so` 由 `ai.onnxruntime` 提供。

离线语音用官方 sherpa-onnx AAR（`app/libs/sherpa-onnx-1.13.8.aar`，Apache-2.0）。`sherpa-ort-align` 插件（`build-logic/convention/.../SherpaOrtAlignPlugin.kt`）在构建期产出打过补丁的副本：摘掉其自带的 `libonnxruntime.so`，并把 `libsherpa-onnx-{jni,c-api}.so` 的 ELF 版本需求从 `VERS_1.28.2` 改写到 `VERS_1.28.0`，使其链接到 `com.microsoft.onnxruntime:onnxruntime-android`（`libs.onnxruntime.android`）提供的 runtime。

app 侧用 `implementation(files(<stripped aar>))` 引入该副本，不需要 CMake `IMPORTED` 目标。

注意 `.gitignore` 的 `*.aar` 会忽略 `app/libs/*.aar`，仓库已用 `!app/libs/*.aar` 放行。升级 AAR 时同步改文件名、插件常量、Gradle 依赖与 `NOTICE.md`；该二进制 47.8 MB，接近 GitHub 单文件 50 MB 警告线。

## 只保留一份 onnxruntime

语音只保留一份 `libonnxruntime.so`。包内那份 runtime 来自 `ai.onnxruntime`，手写 ONNX 引擎已移除；该依赖的 Java API 已无使用者，但 runtime 必须留。

- 不要用 `packaging { jniLibs { excludes += "**/libonnxruntime.so" } }`：`excludes` 不区分来源，会把唯一那份也排掉，实测导致 APK 里 0 份 runtime，语音启动即 `UnsatisfiedLinkError`。
- 应改用 `pickFirsts += "**/libonnxruntime.so"` 兜底：即便将来某个依赖又带回同名 so，也只会保留第一份。
- 版本必须与插件对齐：`libs.versions.toml` 的 `onnxruntimeAndroid` 要对应 `SherpaOrtAlignPlugin` 里的 `toTag`（`VERS_1.28.0`）。两者不一致会在真机上 `UnsatisfiedLinkError`。

验证方式：`unzip -l app-debug.apk | grep libonnxruntime` 必须看到恰好 1 份 `libonnxruntime.so` 与 1 份 `libonnxruntime4j_jni.so`。

## 在线平台没有插件框架

在线语音平台是内置 Kotlin provider，没有插件框架。

新增平台等于写一个 `OnlineAsrProvider` 实现（声明 id、名称、`streamsAudio`、`streamsText`、`isConfigured`、`settings()`、`newSession()`）并在 `OnlineAsrRegistry.providers` 注册一项，设置页与配置表单会自动渲染其字段。

不要再引入 `assets/plugins` 或 Lua 之类的运行期脚本层。

## 输入法服务无法申请运行时权限

`FcitxInputMethodService` 是 Service，录音权限必须经透明中转的 `VoicePermissionActivity`。

结果写 `VoicePermissionState` 这个同进程 StateFlow，IME 面板据此刷新。不要在 IME 里直接 `requestPermissions`。
