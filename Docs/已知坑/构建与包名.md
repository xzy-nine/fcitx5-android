# 构建与包名

构建相关的问题与约束。

## 同包名不能共存

已移除 debug 的 `.debug` 后缀，两个构建签名不同，不能共存安装。切换构建需先卸载，应用内数据会丢。

正确做法：切构建前先在旧版里导出或 WebDAV 备份，装新版后用 `UserDataImportCompat` 导入；历史 debug 备份可直接在无后缀包上恢复。

## CRLF 幻影

`core.autocrlf=true`，Gradle 构建会触碰大量文件，导致 `git status` 出现上百个假 M，其 diff 内容为空。

不要提交它们：`git add --renormalize .` 或重新 `git status` 刷新索引即可消失。

## miuix 依赖版本

`miuix-nav` 仅有 `0.9.4-rc01` 一版，与 miuix-ui 同版本。

其产物为 JVM target 21 字节码，因此 `build-logic/convention/.../Versions.kt` 的 `java` 需保持 `VERSION_21`。这是唯一一条为 Compose 引入的上游 build-logic 改动。
