# 语音预处理

整段语音预处理的配置、算法与接入点。仅用于非流式路径。语音的其它能力见 [语音输入.md](语音输入.md))，进程与打包约束见 [已知坑/语音输入.md](../../已知坑/语音输入.md))。

## 配置

`data/voice/preprocess/VoicePreprocessConfig.kt` 的 `VOICE_INPUT`（`VoicePreprocessConfig.VOICE_INPUT`）取值：

| 参数 | 值 |
|---|---|
| 门限 | 9 |
| 最小语音段 | 160 |
| 合并阈值 | 180 |
| 压缩后保留 | 60（须小于合并阈值） |
| 段前留白 | 60 |
| 段后留白 | 100 |
| 整段快进 | 1.25 |
| 响度均衡 | 开 |
| 目标响度 | -20 |
| 峰值上限 | -1 |

帧长、帧移、输出上限与整段快进倍速的生效值见 `effectiveFastForwardRate`。

## 算法

**`VoiceVad.kt`** 是整段自适应能量 VAD：帧 RMS 转 dBFS，噪声底取 5% 分位、峰值取 98% 分位，门限夹在噪声底加迟滞带与峰值减 12dB 之间，按 3dB 迟滞判决。顺序为连续帧成段、合并近邻、丢弃过短、两端留白、再合并。

**`VoiceSilenceTrimmer.kt`** 负责 `VoiceSegment` 映射表（原样与快进）、拼装、响度均衡、整段快进与统计。首尾静音直接切掉；长停顿按压缩后保留停顿做倍速重采样快进，而不是删除，取 0 才整段移除；整段倍速作用于全部保留音频，音高随倍速升高；兜底路径不做任何处理。

**`VoiceLoudnessNormalizer.kt`** 按语音段 RMS 做整段统一增益，夹在增益上下限内，越界采样削顶到峰值上限。

另含 `VoiceWaveform.kt`（峰值包络）与 `VoiceWavWriter.kt`（16bit PCM WAV）。

## 录音与缓冲

`VoiceUtteranceRecorder.kt` 做无门限无增益的整段录音，与采集链路 `VoiceAudioCapture` 的门限与增益区分。

整段缓冲 `VoiceUtteranceBuffer.kt` 分块累积，`drain()` 调 `VoiceSilenceTrimmer.trim`，取走即锁定不再接新块。

块推送共用 `VoiceEngineAudio.kt`（`PUSH_CHUNK_SAMPLES`、`PUSH_CHUNK_MS`、`forEachPushChunk`）。播放用 `VoicePcmPlayer.kt`（MediaPlayer 播 WAV）。

## 接入点

`VoiceSession.kt` 是非流式接入点：本地离线家族与批次在线平台在松手后 drain、预处理、按 1600 采样分块 push 引擎再 finish；流式家族与 `VolcengineAsrProvider` 仍边采边送，不走预处理。

`VoiceUtteranceRecognizer.kt` 是整段识别入口：给定一段 16kHz 音频出最终文本，本地走复用的 `:asr` 连接按 1600 采样分块 push 后 finish，在线走 provider 会话。它不碰麦克风、不出部分结果，是外部接入的调用点。

## 调试页

`ui/main/compose/screens/VoicePreprocessDebugScreen.kt`：

- 顶部下拉切换本页识别目标，不写回设置。
- 录音、参数改动即时重算。
- 前后波形、语音段高亮、切除遮罩、快进橙色遮罩（`voice_preprocess_compressed`）、门限线。
- 原始与处理后各自可试听、各自出识别结果。
- 试听音频只落 `cacheDir` 临时 WAV，不导出不留存，进出页面各清一次。

入口仅在 `BuildConfig.DEBUG` 下注册（`AppRoute.VoicePreprocessDebug`）。单测在 `app/src/test/java/org/fcitx/fcitx5/android/data/voice/preprocess/`。
