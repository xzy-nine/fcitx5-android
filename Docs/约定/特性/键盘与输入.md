# 键盘与输入

键盘布局、工具栏、候选交互与数字键盘的相关特性。

## 分离式键盘

`BaseKeyboard.kt` 承担重建逻辑，`keyboard/SplitKeyboardLayoutMath.kt` 承担纯计算。

## 工具栏

**高度自定义**：`AppPrefs` 的 `toolbarHeight*`；`KawaiiBarComponent.HEIGHT` 是动态 getter，非 const。

**按钮布局自定义，更多页兼作编辑页**：

- 布局模型 `input/bar/ToolbarLayout.kt`：`ToolbarButton`、`ToolbarLayoutState` 的 docked 与 pool 互斥二分区、`sanitize` 自愈、`resolveDrop` 落点判定。
- 编辑会话 `input/bar/ToolbarEditComponent.kt`：草稿、commit、cancel、落盘语义。偏好 `toolbarDockedButtons`、`toolbarPoolButtons`、`toolbarShowUndoRedo` 不进任何 SubGroup，故应用设置页不出现条目。
- 渲染 `input/bar/ComposeToolbar.kt`：可停靠横向滚动行 + 右侧固定「更多/编辑」，更多页强制显示该行且不隐藏为标题态；另有 `input/bar/ToolbarMovableButton.kt`。
- 拖动 `input/bar/ToolbarDragState.kt`（共享状态，窗口绝对坐标槽位）+ `ToolbarDragGestures.kt`（长按拖、边缘自滚）+ `ToolbarDragOverlay.kt`（挂在 IME 根组合，画幽灵图标与高亮，不吃触摸）。
- 更多页 `input/status/MorePageModel.kt`（池子在上、固定项在下）+ `input/status/ComposeStatusArea.kt`（两段独立滚动网格）+ `StatusAreaWindow.kt`。该窗口已移除主题、输入法选项、虚拟键盘三个跳转项，设置与编辑器信息改为网格格子，不再有 `onCreateBarExtension`。

## 候选交互

**横向候选滑动模式**：`input/candidates/horizontal/ComposeCandidateComponent.kt`，内联实现，勿轻拆。

**空格长按语音输入**：行为由 `SpaceLongPressBehavior.VoiceInput` 提供；图标显隐在 `KeyViewExt.kt`。

## 键盘外观

**顶部圆角裁剪与顶部延伸带**：

- `input/ViewOutlineExt.kt` 做圆角裁剪；`input/ImeTopCorner.kt` 是半径单一真源 `IME_TOP_CORNER_RADIUS_DP=16`。
- 顶部延伸带是 `composeTopView` 在预编辑栏与工具栏之间插入的恒高 Box（等于圆角半径，透出键盘底色与背景图），键盘体上缘抬到 app 可视区之上。
- `InputView.topExtensionPx` 由 `FcitxInputMethodService.onComputeInsets` 加回 `contentTopInsets`，不计入 insets。

## 数字键盘

**横屏分体与历史符号**：

- Compose 路径 `ComposeNumberKeyboard.kt`（分体分支）+ `ComposeRecentSymbols.kt`（历史符号面板）+ 同文件 `ComposeSymbolSlider`（符号滑块）。
- 行数据 `NumberKeyboardRows.kt` 为单一实例 val。
- 布局为左 45% 历史符号网格 + 右 45% 符号滑块或 9 宫格，中间 10% 分隔。
- View 版 `NumberKeyboard.kt`、`RecentSymbolsView.kt` 已断线保留。

**解耦**：主键盘 `?123` 恒进 9 宫格（`TextKeyboard.kt` 指向 `NumberKeyboard.Name`），`!?#` 进符号页。`KeyboardWindow.kt` 无 `lastSymbolType`；`last_symbol_layout` 是孤儿配置，勿用。

## 包名

**包名统一与历史 debug 备份兼容导入**：

- `build-logic/convention/.../AndroidAppConventionPlugin.kt` 移除 `.debug` 后缀，`AndroidPluginAppConventionPlugin.kt` 同步占位符。
- 导入兼容层 `data/UserDataImportCompat.kt`。
- `app_name`、`app_icon`、`app_icon_round` 的 resValue 上提到 `defaultConfig`。
