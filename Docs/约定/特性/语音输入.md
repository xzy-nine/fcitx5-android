# 语音输入

内置语音输入、离线多家族支持与整段预处理的相关特性。语音的进程约束与打包坑见 [已知坑.md](../../已知坑/语音输入.md))，第三方插件协议见 [语音插件接入.md](../../集成/语音插件接入.md)。

## 内置语音输入

IME 面板加应用设置页。离线用 sherpa-onnx，在线支持火山与 MiMo。自有代码许可为 LGPL-2.1-or-later。

- 离线 `app/libs/sherpa-onnx-1.13.8.aar`，构建期由 `sherpa-ort-align` 摘除自带 ONNX，改由 `ai.onnxruntime` 提供。
- 离线代码 `data/voice/`：`VoiceAsrService.kt`（`:asr` 进程）、`VoiceAsrClient`、`VoiceAudioCapture`、`VoiceSession`、`VoiceSpectrum`、`VoiceTextRules`。
- 在线代码 `data/voice/online/OnlineAsrProvider.kt`，实现有 `VolcengineAsrProvider` 与 `MiMoAsrProvider`。
- 模型管理 `VoiceModelStore`、`VoiceModelCatalog`。
- UI 在 `input/voice/`；设置页 `VoiceInputSettingsScreen`、`VoiceProviderConfigScreen`；录音权限 `VoicePermissionActivity`。

## 离线多家族支持

在线与离线两套识别器，按元数据判家族。

- 家族枚举与文件形状 `data/voice/VoiceModelFamily.kt`：`VoiceModelFamily` 的 streaming 标志、`VoiceModelSpec`（跨 AIDL 的单位）、`VoiceFileShape.roles` 与 `shapeCandidates`。
- 元数据直读 `data/voice/OnnxMetadata.kt`：自解析 ONNX `metadata_props`（ModelProto 14 号字段），免开 ORT 会话。
- 家族判定 `data/voice/VoiceModelClassifier.kt`。
- 引擎分派 `data/voice/VoiceSpeechEngine.kt`：`SpeechEngine` 接口 + `StreamingEngine` 与 `OfflineEngine`，按 family 只构造一次。
- AIDL `IVoiceAsrService` 传 `family`、平行数组 `roles[]` 与 `paths[]`、`language`、`inverseTextNormalization`。

三条硬约束：

1. 家族判错会让原生构造函数走 `SHERPA_ONNX_EXIT`（`_Exit`）直接杀 `:asr` 进程，因此禁止运行期试错回退，判不出就拒绝（`VoiceModelClassifier.Result.Unknown`）。
2. `metadata_props` 在 protobuf 里排在 `graph` 之后，读它要顺序跳过整个 onnx，因此 `VoiceModelStore.resolve` 只能在 IO 线程调用；市场页的 `isReady` 只做文件形状判定。
3. 支持范围为在线 transducer（含 NeMo、parakeet）、paraformer、zipformer2-ctc、nemo-ctc、t-one；离线 transducer、paraformer、whisper、sense-voice、zipformer-ctc、nemo-ctc、wenet-ctc、firered（含 ctc）、medasr、telespeech、dolphin。不支持 Moonshine、Qwen3-ASR、Omnilingual（构造不读任何元数据，无法从模型自身还原）、在线 WeNet CTC（Kotlin API 的 `OnlineModelConfig` 未暴露 `wenetCtc` 字段），以及 rknn、qnn、axera、ascend、spacemit 等特殊芯片后端。
