# 手写与模型市场

手写键盘、识别引擎、触控笔手写与模型市场公共组件的相关特性。

## 手写输入

第三种键盘布局。识别引擎为系统内置或谷歌数字墨水，自有代码许可为 LGPL-2.1-or-later。

- 识别后端 `data/handwriting/HandwritingRecognition.kt` 与 `HandwritingEngineKind.kt`。
- 纯逻辑 `HandwritingStrokeFx.kt`、`HandwritingTypes.kt`。
- UI `input/handwriting/HandwritingKeyboardLayout.kt`（镜像 L 布局）与 `HandwritingInputComponent.kt`。
- 入口是工具栏按钮，落 `KeyboardWindow` 第三布局。
- 上屏原语 `FcitxInputMethodService.replaceBeforeCursor` 与 `deleteBeforeCursor`。
- 设置 `AppPrefs.Handwriting` 与 `HandwritingSettingsScreen`。

## 手写识别引擎

统一入口，两档后端。

- 统一入口 `data/handwriting/HandwritingRecognition.kt` 与 `HandwritingEngineKind.kt`（`chainFrom()` 引擎链）。
- 系统后端 `XiaomiHandwritingEngine.kt`：反射 `/system_ext/framework/xiaomi-pencilengine-pad.jar`，`recognizeText` 整段单结果，另有 `getGoogleGesture`。
- 谷歌后端 `GoogleDigitalInkEngine.kt`：ML Kit `digital-ink-recognition:19.0.0`，模型运行时下载，`<tag>-x-gesture` 手势分类器经 `GoogleGestureLabels.kt` 映射。
- 内置模型 `MlKitBundledModel.kt`：`DigitalInkModelPlugin.kt` 构建期拉取，物化到 `files/mlkit_digital_ink_recognition/.../datadownloadfile_<ts>/`。
- 设置 `AppPrefs.handwriting.handwritingEngine`。

## 触控笔手写

基于 Android 13+ 触控笔手写协议。

- `input/handwriting/StylusHandwritingController.kt` 是会话控制器，同文件含 `StylusInkView`（原生墨迹 View，非 Compose）。
- `StylusToolboxView.kt` 的 `StylusToolboxWindow` 把工具箱 addView 到 IME 窗口 decorView。
- 演示页 `ui/main/compose/screens/HandwritingGestureDemoScreen.kt`。
- 上屏为整段墨迹累积：抬笔 `STYLUS_SETTLE_MS=500` 到点后二选一执行 `tryConsumeAsGesture()` 或 `commitRecognition()`。
- 手势三态状态机 `advanceGestureState()`；系统引擎优先，否则谷歌手势分类器；坐标走屏幕坐标系。
- `FcitxInputMethodService` 锚点 `onUpdateEditorToolType`、`onPrepareStylusHandwriting`、`onStartStylusHandwriting`、`onStylusHandwritingMotionEvent`、`onFinishStylusHandwriting`。
- 前置 `res/xml/input_method.xml` 的 `android:supportsStylusHandwriting="true"`。

## 模型市场

语音与数字墨水共用的公共组件。

- 公共层 `data/market/`：`MarketModel.kt`（数据类型）、`MarketCategory` 接口、`BaseMarketCategory` 公共实现（`runTrackedDownload` 下载骨架）、`MarketCategories` 注册表、`MarketCategoryIds`、`MarketArchive.kt`（`extract`、`installFromStream`、`promote`，支持 tar.bz2、tar.gz、tar、zip，剥首层 + slip 防护 + 暂存目录探针 `.staging`）、`MarketModelGrouping`（语言变体分组）、`ModelDownloader`、`MarketModelId` 与 `MarketPaths`。
- 分类实现 `data/voice/VoiceMarketCategory.kt` 与 `data/handwriting/DigitalInkMarketCategory.kt`。
- UI `ui/main/compose/screens/ModelMarketScreen.kt` 与 `ModelMarketHomeScreen.kt`。
- 清单全部内置，无远程索引。原 `ModelIndex`、`kaml`、`voiceIndexUrl` 已移除。语音内置 9 条官方 release 资产（`VoiceModelCatalog`）。
- 支持手动导入清单外归档到模型根目录：`supportsImport`、`importModel`，SAF `GetContent` 无需存储权限；`refreshIndex` 每次从文件系统派生导入项。

升级 sherpa AAR 时须按新版本 release 复核 `VoiceModelCatalog` 的资产名。
