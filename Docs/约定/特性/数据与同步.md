# 数据与同步

数据预同步、剪贴板广播、WebDAV 备份、本地网络权限与邮箱联想的相关特性。

## 启动期数据目录预同步

`core/data/DataSyncPreloader.kt` 在后台线程预热 `DataManager.sync()`，`Fcitx.nativeStartup` 处 `await()` 等它完成。

## 剪贴板广播与配对

独立包 `data/broadcast/*`，配 `BroadcastPairingService.kt` 与 `IBroadcastPairingService.aidl`。

**备份忽略广播配对**：Room `databases/broadcast_db` 的 `PairedAppEntity.keyAlias` 指向本机 Keystore 密钥；备份经 `BroadcastBackupFilter` 剔除该库；导入不动本机已有有效配对。

## WebDAV 云端备份同步

覆盖偏好 zip 与词库逐文件两条链路。

**模块与界面**：`sync/webdav/*`（Config、DictCollector、PrefsCollector、BackupZips、WebDavSyncEngine、SyncRestorer、AutoDictSync、AutoPrefsBackup、DictReload、DictMerger、PendingDictMerge）；UI 在 `ui/main/compose/screens/WebDavSyncScreen.kt`；偏好 zip 走 `UserDataImportCompat`。

**词库逐文件同步**：`uploadDictFiles` 与 `downloadDictFiles` 按 `data/` 相对路径映射。

**组合叠加不覆盖**：由 `DictMerger` 承担。拼音 `user.dict` 与导入 `.dict` 走 JNI 转文本后按行并集；`customphrase` 与 QuickPhrase `.mb` 直接按行并集；`user.history`、`table/*` 分段结构、`inputmethod/*.conf` 仍整体覆盖。并集后清本地摘要以把并集推回云端。

**引擎自持词库**：`pinyin/user.dict` 由 `PendingDictMerge` 延后到引擎停机后再叠加。

**热重载与重建**：`DictReload` 对 pinyin、customphrase、quickphrase 热重载；table 与 user.dict 需要重建进程。

**自动同步**：`AutoDictSync.startAutoSync()` 常驻 tick（`syncOnce`）双向兜底，并对词库变更事件去抖上传。上传前先 `save()` 落盘引擎自学习词库；首次同步（`dictFileDigests` 为空）只下载不上传；顺序为先下载叠加再上传；下载写盘前复查键盘可见性。

**自动备份偏好**：独立开关 `prefsAutoSync`，仅上传（`AutoPrefsBackup` → `uploadSettingsBackup`）。内容为 `shared_prefs` 与 `external/config`，不含 databases。按 `PrefsCollector` 内容指纹跳过未变化项，计算前剔除 `pid`、`last_crash_time` 等易变键。文件名 `fcitx5-settings_auto-<device>.zip`。

Manifest 声明 `INTERNET`、`ACCESS_NETWORK_STATE` 与 `res/xml/network_security_config.xml`。

## Android 17 本地网络权限

- 判定与授权在 webdav 子模块 `github.xzynine.webdav.LocalNetworkPermission`（`isLocalNetworkUrl`、`isGranted`、`needsRequest`），子模块清单声明 `ACCESS_LOCAL_NETWORK`。
- 宿主侧界面门 `ui/main/compose/LocalNetworkPermissionGate.kt`（`rememberLocalNetworkPermissionGate()`、`ensure(url)` 挂起等系统权限框）接入 `WebDavSyncScreen` 全部网络入口。
- 引擎兜底 `sync/webdav/LocalNetworkGuard.kt`：在 `WebDavSyncEngine.webDav()` 唯一出口处 `require(url)`，抛 `LocalNetworkPermissionRequiredException`；`AutoDictSync` 后台链路无权限时静默跳过。
- 前置条件 `Versions.targetSdk = 37`。

## 邮箱域名联想

基于 QuickPhrase 词库与 App 层触发。

- 词库条目形如 `@域名 域名`。内置词库 `usr/share/fcitx5/data/quickphrase.d/email.mb`（CMake 从 `app/src/main/cpp/email/email.mb` 安装）；用户词库 `getExternalFilesDir(null)/data/data/quickphrase.d/email.mb`。
- App 层 `data/quickphrase/EmailDomainDict.kt` 做自学习 MRU。
- 触发锚点 `FcitxInputMethodService.commitText` 末尾的 `onEmailSuggestionTrigger`。
- JNI `native-lib.cpp` 加 `triggerQuickPhraseWithBuffer`。
