# 环境适配

为在本地与 fork 环境构建而引入的适配。这些改动不应出现在上游 PR 中。

| 位置 | 适配内容 |
|---|---|
| `.gitmodules` | 全部 submodule 指向 `gitee.com/xzy-ime` 镜像 |
| `gradle.properties` | `ndkVersion` |
| gradle-wrapper | 华为云镜像 |
| `FindFcitx5Utils.cmake` | WIN32 MSYS2 gettext 路径 |
| thai 插件 | Iconv CACHE 补丁 |

镜像子模块可能出现哈希不存在的情况，此时需先同步镜像仓库再重试。构建前置与子模块初始化见 [构建与验证.md](../../工程/构建与验证.md)。
