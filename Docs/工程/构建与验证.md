# 构建与验证

从仓库根构建、验证与性能诊断的入口。版本与 ABI 以 [Versions.kt](../../build-logic/convention/src/main/kotlin/Versions.kt) 为准。

## 工具链

使用 Java 17、Android SDK 36、NDK `28.0.13004108`、CMake `3.31.6`。

## 构建 ARM64 Debug

```sh
./prepare_personal_build.sh
./gradlew -PbuildABI=arm64-v8a :app:assembleFxDebug
python3 tools/verify-direct-rime-apk.py app/build/outputs/apk/fx/debug/*.apk
python3 tools/audit-direct-rime-link.py app/build/outputs/apk/fx/debug/*.apk
```

产物在 `app/build/outputs/apk/fx/debug/`。

非空 `BUILD_ABI` 环境变量优先于 `-PbuildABI`；支持逗号分隔；均未设置时构建全部 ABI。

JVM 测试任务为 `:app:testFxDebugUnitTest`，按改动选择测试与设备门禁，见 [测试策略.md](测试策略.md)。

## Windows

使用 `gradlew.bat` 和可用的 Python。没有 Bash 时执行 `git submodule update --init --depth 1 native/rime-prelude`，再执行 `./gradlew.bat prepareRimeSdk`。

Python 门禁传入本次 APK 的实际路径。维护文档中的本机 PowerShell 脚本不随仓库分发，无需复制作者的盘符与目录结构。

## 引擎来源

内置引擎来自 [SandyYuR/librime 的 zhongzhou](https://github.com/SandyYuR/librime/tree/zhongzhou)，由 [native/rime-sdk.lock.json](../../native/rime-sdk.lock.json) 固定 SDK 版本与摘要，Gradle 下载并校验。

用户另行授权的 `.so` 或引擎提供 APK 属于运行时变体，不改写该锁。共享预设 `native/rime-prelude` 是唯一子模块；当前构建不使用旧 prebuilder 或 prebuilt。开发 SDK 仅显式接入 Debug，详见[原生依赖说明](../../native/README.md)与[引擎更新流程](https://sandyyur.github.io/fcitx5-android/maintainer/engine-update)。

## 构建开关

- `-PinputDiagnostics=true`：逐键性能诊断，与用户开启的统计、词云功能独立。
- `-PdirectRimePrototype=true`：额外包含 `.lab` 诊断模块；日常构建无需选择后端。

## 文档门禁

依赖用 pnpm 安装，门禁由 `scripts/doc-system.config.ts` 统一定义扫描范围。

```sh
pnpm install        # 安装门禁依赖
pnpm run verify-all # 全部门禁
pnpm run test:docs  # 同一条命令，供 CI 使用
```

Gradle 侧注册了 `verifyDocs` 任务，`./gradlew check` 会先跑文档门禁，再跑各模块的 `check` 与 `:app:testFxDebugUnitTest`。首次运行前需先 `pnpm install`。
