# 模块结构

Gradle 模块划分与 `app` 内部包职责。数量为当前源码文件数，作为规模参考，不随每次改动同步。

## Gradle 模块

| 模块 | 职责 |
|---|---|
| `:app` | 输入法主程序，包含 IME 界面、设置界面、数据层与语音／手写等全部功能 |
| `:lib:common` | 主程序与插件共用的类型与工具 |
| `:webdav` | WebDAV 客户端，包名 `github.xzynine.webdav`，含本地网络权限判定 |
| `:direct-rime` | Rime 直连支持 |
| `:codegen` | 构建期代码生成 |

`lib/*` 与 `plugin/*/src/main/cpp/*` 是 git submodule，承载 native 源码，不作为独立 Gradle 模块参与构建。

## app 内部包

| 包 | 文件数 | 职责 |
|---|---|---|
| `input` | 273 | IME 输入层：键盘窗口与布局、候选栏、预编辑、Picker、剪贴板、文本编辑、状态区、弹窗层、语音面板、手写面板、窗口宿主 |
| `ui` | 171 | 应用界面：Compose 导航与设置、主题、模型市场、各功能设置页 |
| `data` | 143 | 数据层：偏好、词库、语音、手写、模型市场、市场归档、广播配对、导入兼容 |
| `utils` | 70 | 通用工具：日志、协程、视图扩展、字体与资源辅助 |
| `core` | 51 | 核心服务：fcitx 引擎桥接、数据同步预加载、启动追踪 |
| `sync` | 12 | 云端同步：WebDAV 引擎、自动同步、词库合并与重载 |
| `daemon` | 3 | fcitx 守护进程控制 |
| `provider` | 2 | 插件提供者入口 |

## 输入层的子目录

`input` 下的子目录按窗口与控件划分，改动前先确认所属子目录的正家。

| 子目录 | 内容 |
|---|---|
| `input/keyboard` | 键盘布局、键视图、手势、分体布局计算、布局名常量 |
| `input/candidates` | 横向候选栏、展开候选、浮动候选、候选操作菜单 |
| `input/candidates/horizontal` | 横向候选的 Compose 实现与状态 |
| `input/candidates/expanded` | 展开候选的 Compose 实现、分页、样式与刷新 |
| `input/picker` | 符号、表情、颜文字 Picker 的页面模型、网格布局与窗口 |
| `input/clipboard` | 剪贴板主页、编辑页与文本分析 |
| `input/editing` | 文本编辑窗口 |
| `input/status` | 状态区与更多页 |
| `input/popup` | 弹窗层与布局计算 |
| `input/preedit` | 预编辑组件 |
| `input/bar` | 工具栏组件、布局模型、按钮拖动 |
| `input/voice` | 语音输入面板 |
| `input/handwriting` | 手写键盘布局、输入组件、触控笔会话 |
| `input/wm` | 输入窗口管理与 Compose 浮窗宿主 |
| `input/editorinfo` | 编辑器信息窗口 |
